Range-Based for loop allows easy iteration over a range. It internally expands to a loop. That loop uses iterators to iterate over the range.  So, the container that is used in range-based for loop should support iterators and those iterators have to support certain overloaded operators. For the end condition, the begin and end iterators must be same. This was required until C++14. 

In C++17, this restriction is removed. Now, begin and end can be of different types, but the iterator must provide not equal to operator for comparison. In C++17, this is the expansion of a range-based for loop. Now, begin and end can be of different types, but there should be a comparison operator that can compare begin and end.
