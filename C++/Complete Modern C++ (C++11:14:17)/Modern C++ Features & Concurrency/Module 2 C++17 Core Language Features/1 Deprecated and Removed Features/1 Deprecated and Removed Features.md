Hi, I will now discuss some features that were deprecated in C++11 and 14 but now have been removed from the C++17 standard. [no audio] register was one of the storage classes in C++98. It was a hint to the compiler that specified that the variable should be stored in a register. It was useful for optimization. However, this optimization is no longer required in modern compilers. That is why this storage class is now removed in C++17. Even if you use it, it has no effect on the semantics of the program. You may also get a warning from the compiler. 

Before C++17, you could apply the increment operator on a Bool type. Now, this is removed in C++17. Decrement operators were never allowed. If you try to compile the code that uses the increment operator with C++17 compiler, the code will not compile. It is a compiler error. On some older PCs, the keyboard did not support many characters that were required in programming languages. So, these special characters were inserted into the code through Trigraphs. 

A Trigraph is a special sequence of characters and it is interpreted by the compiler as a symbol. For example, this combination produced a tilt. These are no longer required now because the keyboards have support for special characters. That is why these have been removed from the language. And because of this, it may speed up the compilation process because the compiler does not have to translate these special characters to a different character. Exception specifications were a C++98 feature. This allowed a function to advertise what exceptions it throws. 

The throw statement would follow the function name and in the throw statement you could write the names of the exceptions that the function would throw. But even then, it was not implemented by many compilers. That is why it was deprecated in C++11 and replaced by the noexcept specifier. If you try to use it with the modern compiler, then the compiler may issue a warning. The last feature that was removed from C++17 is the Auto Pointer. This was a smart pointer added in C++98. The problem with this class was that it had no ownership semantics and it could lead to bugs. 

For example, if you assign one smart pointer to the other smart pointer, then the ownership would get transferred automatically. It was replaced in C++11 with unique pointer and shared pointer. If you have legacy code that uses auto_ptr, you can replace auto_ptr with unique pointer. Some library functions were also deprecated and removed. Random shuffle was an algorithm that could shuffle a list of elements, but it was dependent on the C function rand. It is now replaced with the shuffle algorithm. unary_function and ptr_fun have been replaced by function. bind1st, bind2nd have been replaced with bind.
