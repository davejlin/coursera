Hi, in this lecture, I will give you an introduction to the Parallel STL Algorithms. By default, STL Algorithms will execute serially. That means all the operations that are performed in the algorithm are performed on a single thread. C++17 added the parallel versions of many STL algorithms. These are simply overloads of the existing algorithms and can execute parallelly. This means operations on the elements inside the algorithm will be performed on different threads and at the same time. So, the threats will execute parallelly. 

Algorithms that can be parallelized accept a new template parameter. This is called execution policy. It is used to disambiguate the calls to the overloads of the algorithm. This execution policy is used to inform the algorithm if it can execute serially or parallelly. The internal implementation details of the parallel algorithms are hidden to the user.
